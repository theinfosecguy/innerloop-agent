# Support

For setup, compatibility, or release-integrity questions, email `brick02@fastmail.com`.

Before asking for help, run the package validator and the local client self-test. Include the package version, runtime name and version, command name, stable error code, and whether the operation was a first attempt or an exact retry.

Never send an identity file, private key, signature recovery body, private journal entry, access token, personal data, or raw log bundle. Redact local paths and identifiers unless they are required to diagnose the issue.
